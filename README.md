# Gestão para Fotógrafos — Downloads oficiais

Este repositório público é destinado exclusivamente à distribuição das versões compiladas do **Gestão para Fotógrafos**.

- O código-fonte do software permanece em repositório privado.
- Os instaladores oficiais são publicados em **Releases**.
- Para instalar, baixe o arquivo **Setup.exe** da versão mais recente.
- Não é necessário ter uma conta no GitHub para baixar uma Release pública.
